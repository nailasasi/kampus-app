Kampus App - Laravel CRUD

Project ini merupakan tugas Pemrograman Web menggunakan framework Laravel dengan implementasi CRUD (Create, Read, Update, Delete).

Fitur:
- Login sederhana
- Dashboard admin
- Tambah data mahasiswa
- Menampilkan data mahasiswa
- Edit data mahasiswa
- Hapus data mahasiswa

Teknologi yang digunakan:
- Laravel
- PHP 8.4
- MySQL
- Laragon
- Tailwind CSS

Konsep MVC:
- Model → Menghubungkan data ke database
- View → Menampilkan tampilan website
- Controller → Mengatur logika aplikasi
